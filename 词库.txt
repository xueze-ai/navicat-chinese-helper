# Navicat 中文助手 · 错误码词库
# 格式（用制表符 Tab 分隔）：错误码	中文翻译	建议（建议可以为空）
# 占位符说明：
#   {1} {2} ...   = 英文消息里第 1、2... 个「带引号的参数」
#   {N1} {N2} ... = 英文消息里第 1、2... 个数字
#   万一某个占位符取不到值，程序会显示成「？」，并在下面附上英文原文，不会给出错误的解释。
# 以 # 开头的行是注释。同一个错误码可以写多行。
#
# 【来源】英文模板取自本机 MySQL 8.0 官方错误消息（mysql/bin/perror.exe 导出，共 888 条），
#         中文为逐条人工翻译，不是机器翻译。想加自己的条目，照着格式追加即可。
