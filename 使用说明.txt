Navicat 中文助手 · 使用说明
================================================================

【这是什么】

一个独立的小工具。它盯住 Navicat 的「信息」面板，你在 Navicat 里执行 SQL 之后，
面板里出现的英文报错会被自动翻译成中文，显示在工具窗口里。

全程不需要复制、不需要粘贴、不需要联网、不需要额外装任何东西。


【怎么用】

1. 双击「Navicat中文助手.exe」。窗口会出现在屏幕右下角，并且一直置顶。
2. 正常使用 Navicat，执行你的 SQL。
3. 每执行一次，工具窗口里就会多一条，长这样：

   ── 11:10:08 ──────────────────────────────
   执行：USE dcsefde
   【错误 1049】未知数据库 'dcsefde'
       建议：数据库名拼写错误，或该库不存在
       原文：1049 - Unknown database 'dcsefde'
   耗时： 0.001s

   翻译在「【错误 编码】」那一行；下面灰色的是原始英文，方便对照。
   执行成功、没有报错时会显示【执行成功】没有报错。


【窗口上的按钮】

  暂停      临时停止监听（再点一次继续）
  清空      清空当前显示的内容（不影响 Navicat）
  复制全部  把窗口里全部内容复制到剪贴板
  词库      用记事本打开词库文件，可以自己补充词条
  载入词库  改完词库后点一下，不用重启程序
  置顶      让窗口始终显示在最前面

不想用的时候直接关窗口，它会最小化到右下角托盘；右键托盘图标可以退出。


【它是怎么做到的】

Navicat 官方没有提供插件接口，所以做不成真正的 Navicat 插件，只能用外挂的方式：

  1. 用系统自带的 Win32 接口（EnumChildWindows）找到 Navicat「信息」面板那个文本框；
  2. 直接取它的文字，所以不需要截图识别（OCR），也不需要你复制粘贴；
  3. 解析出错误码和英文原文，去本地词库查中文，显示出来。

词典里目前有 186 个 MySQL 常见错误码。中文说法是照着 MySQL 官方
（perror.exe / share\messages_to_clients.txt）的英文模板逐条写的，不是机翻。
碰到词库里没有的错误码，它会原样显示英文并标注「词库暂无此码」。


【想增加词条？】

用记事本打开「词库.txt」，一行一条，三列，用 Tab 键分隔：

    错误码 <Tab> 中文说法 <Tab> 建议

  例如：
    1049    未知数据库 '{1}'    数据库名拼写错误，或该库不存在

写法说明：
  {1} {2} ...      英文原文里第 1、2 个「单引号参数」的值
  {N1} {N2} ...    英文原文里第 1、2 个数字
  以 # 开头的行是注释，不会被读取
  同一个错误码可以写多行（对应英文的不同说法），程序会自动挑参数能套上的那条

想查到某个错误码的官方英文原文，可以在命令行里跑（按你自己的 MySQL 安装路径）：

    "E:\IDEA\MySQL\MySQL Server 8.0\bin\perror.exe" 1049 1062

改完词库，点窗口上的「载入词库」即可生效。


【开机自动启动（可选）】

  1. 右键「Navicat中文助手.exe」→ 发送到 → 桌面快捷方式；
  2. 按 Win+R，输入 shell:startup 回车；
  3. 把桌面上的快捷方式拖进打开的文件夹里。


【常见问题】

Q：窗口里一直没内容？
A：先在 Navicat 里随便执行一句会报错的 SQL（比如 USE 一个不存在的库）试试。
   另外确认 Navicat 底部的「信息」面板是打开的（和「状态」「剖析」并列的那个页签）。
   工具状态栏会显示「已连接 Navicat（N 个结果面板）」，说明已认出面板。

Q：双击 exe 没反应 / 提示缺东西？
A：本工具用系统自带的 .NET Framework 4.x，Windows 10/11 默认就有。
   若确实弹出缺 .NET 的提示，装一下 .NET Framework 4.8 即可。

Q：会不会把数据改坏？
A：不会。工具只读 Navicat 面板上的文字，从不向 Navicat 写入任何内容。

Q：Navicat 关掉再打开还能用吗？
A：可以，工具会自动重新找到新窗口，不用重启。


【目录里都有什么】

  Navicat中文助手.exe      主程序，双击运行
  词库.txt                 错误码中文词库，可以自己加
  使用说明.txt             本文件
  NavicatChineseHelper.cs  源码（C#，想改功能改这个）
  编译.bat                 改完源码后双击它重新编译，生成新的 exe
  build.ps1                编译.bat 实际调用的脚本，一般不用直接运行
  自检结果.txt             自检输出，用来核对词库和翻译是否正确
  诊断日志.txt             排查用日志，只有加 --debug 参数启动时才会写入


【命令行参数（一般用不到）】

  Navicat中文助手.exe --selftest    不做监听，只跑一遍翻译自检并写 自检结果.txt
  Navicat中文助手.exe --debug       写 诊断日志.txt，用于排查读不到面板的问题
